## Summary

KisanSaarthi is a voice-first procurement platform solving PS26032 —
farmers facing long waits, unclear schedules, and no visibility into
procurement status at government centres.

**Built:**

- React frontend with role-based dashboards (Farmer, Staff, Admin)
- FastAPI backend with capacity-aware approval logic and real-time queue management
- Supabase/PostgreSQL database
- Working AI voice callbot (Vapi) for booking and status checks by phone
- Fully deployed (Netlify + Railway + Supabase) — not just a local demo

**Planned:**

- BHASHINI integration for regional-language voice support
- DTMF keypad fallback for basic phones
- SMS notification service for status updates

operational viability, and impact analysis.
