# Demo Video

**Video link:** https://youtu.be/WfK0KywXLaA?si=C-9KZBbpf8PuDehh

## What the video covers

1. **Website walkthrough** — Homepage, login (email/phone), farmer
   requesting a token, staff approving it, farmer seeing the live status
   update, and the admin panel.
2. **Voice callbot** — A live call demonstrating the Vapi-based callbot
   identifying a farmer and handling a booking or status request.
3. **Deployment proof** — Live Netlify, Railway, and Supabase deployments,
   confirming this is a fully working hosted system, not a local-only demo
